# DebtTrack — учёт долгов (Android)

Приложение для учёта личных долгов: кому должны вы и кто должен вам,
с историей платежей, статистикой и напоминаниями о сроках возврата.

## Стек технологий
- **Kotlin**, Android Studio
- **Room** — локальная база данных (SQLite)
- **MVVM**: ViewModel + LiveData/Coroutines
- **Navigation Component** — навигация между экранами
- **MPAndroidChart** — круговая диаграмма на экране статистики
- **WorkManager** — фоновые напоминания о приближающемся сроке возврата
- **DataStore** — хранение пользовательских настроек

## Экраны
1. Главная (список долгов, сводка баланса)
2. Новый долг (создание/редактирование)
3. Детали долга (просмотр, история платежей, удаление)
4. Добавить платёж
5. Статистика (диаграмма, топ долгов)
6. Настройки (тема, сортировка, уведомления)

## База данных
Таблицы: `Category`, `Debt`, `Payment`, `Tag`, и промежуточная `DebtTagCrossRef`
(многие-ко-многим между Debt и Tag). Подробнее — см. `DebtTrack_План_разработки.md`.

## Как открыть проект
1. Открыть Android Studio → Open → выбрать папку `DebtTrack`
2. Дождаться синхронизации Gradle (потребуется интернет — подтянутся зависимости, включая MPAndroidChart с JitPack)
3. Запустить на эмуляторе/устройстве (minSdk 24)
